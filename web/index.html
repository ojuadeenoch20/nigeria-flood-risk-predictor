About this model

Trained on a Gradient Boosting classifier using five real, satellite-derived features across roughly 5,600 sampled locations in Nigeria, with flood outcomes drawn from the Global Flood Database, a real record of observed flood events from 2000 to 2018.

Performance

On held-out test data, the model catches 86% of real flood locations, 31 of 36, with 114 false positives out of 1,366 genuinely safe locations. The classification threshold was deliberately lowered from the model's default, since missing a real flood is treated as a more costly error than a false alarm.

Limitations

  • Flood outcome data only extends through 2018
  • Five environmental features only. Real flood risk also depends on drainage infrastructure, waste management, and dam operations, which aren't captured here
  • Forest loss data has occasional coverage gaps in drier regions. When missing, it's treated as zero
  • Built as a research and portfolio project, not an authoritative early warning system

Privacy and data use

This site does not use cookies, does not run analytics or third-party trackers, and does not create user accounts. The only data it collects is the location you submit to get a prediction.

What happens to a submitted location

The coordinates you enter are sent to the prediction API, used to query public satellite datasets and run the model, and returned to you as a result. They are not stored, logged, or shared beyond what's needed to serve that single request.

Third-party data sources

Predictions are generated using public datasets from Google Earth Engine, including CHIRPS, SRTM, ESA WorldCover, JRC Global Surface Water, the Hansen Global Forest Change dataset, and the Global Flood Database. These are read-only queries; no personal data is sent to these providers.

About this project

Built as an independent research and portfolio project exploring whether real satellite data can meaningfully predict flood risk in Nigeria, starting from a synthetic baseline dataset and progressing to a full pipeline built on real environmental and historical flood data.

The source code, including the data pipeline, model training process, and this site, is public on GitHub.
